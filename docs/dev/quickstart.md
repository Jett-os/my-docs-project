# Быстрый старт для разработчика

## Порядок локального развертывания бэкенда
1. Установите зависимости: `pip install fastapi uvicorn pydantic`
2. Запустите сервер: `uvicorn main:app --reload`
3. Интерактивная документация Swagger доступна по адресу: http://127.0.0.1:8000/docs
3. Внутри этой же папки docs/dev/ создайте файл api_endpoints.md (это уберет предупреждения сборщика о пустых ссылках) и вставьте туда базовый шаблон:
# Спецификация эндпоинтов API

## 1. Получение аналитики абонемента студента
* **URL:** `/api/v1/students/{student_id}/subscription`
* **Метод:** `GET`

### Параметры запроса (Path):
| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| `student_id` | `integer` | Номер студенческого билета (например, `202601`) |

## 2. Добавление книги в абонемент студента
* **URL:** `/api/v1/students/{student_id}/borrow`
* **Метод:** `POST`

### Параметры пути (Path Parameters):

| Параметр | Тип | Обязательный | Описание |
| :--- | :--- | :--- | :--- |
| `student_id` | `integer` | Да | Уникальный идентификатор студента (номер билета) |

### Структура тела запроса (JSON Body):

| Поле | Тип | Обязательный | Описание | Пример |
| :--- | :--- | :--- | :--- | :--- |
| `book_id` | `string` | Да | Международный стандартный номер книги (ISBN) или ID | `978-5-93700-113-9` |
| `days_requested` | `integer` | Да | Количество дней, на которое берется книга (1–180) | `14` |

### Пример тела запроса (Request Body):
```json
{
  "book_id": "978-5-93700-113-9",
  "days_requested": 14
}
```

### Пример успешного ответа сервера (Response 201 Created):
```json
{
  "status": "success",
  "message": "Книга успешно добавлена в абонемент студента.",
  "data": {
    "borrow_id": 14820,
    "student_id": 202601,
    "book_id": "978-5-93700-113-9",
    "borrowed_at": "2026-05-25T12:40:00Z",
    "return_deadline": "2026-06-08T12:40:00Z"
  }
}
```
